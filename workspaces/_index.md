# Workspaces

One folder per employer: `workspaces/<company>/context.md` (stage, ARR band, ACV, motion, ICP, current bottleneck, OKRs). `/advise`, `/advise-deep` and `/red-team` read the active one. Set one up with `/workspace-setup <company>`.

**Everything in here except this file is git-ignored.** It belongs to the employer and is deleted when the owner leaves. Before creating one, check the employer's AI policy — their context may belong in their own sanctioned tool instead.

Lessons can graduate from a workspace to `playbooks/`. Data never does.
