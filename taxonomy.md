# Taxonomy

The fixed tag list. Web Clipper's tag prompt, `/process-inbox` and `/advise` all read from here. **Add a tag only when three or more library notes would use it** (at `/setup`, add the ones you expect to need).

| Tag | Covers |
|---|---|
| `demand-gen` | Pipeline creation, channels, paid, events, ABM |
| `plg` | Product-led growth, self-serve funnels, activation, freemium |
| `product-marketing` | Launches, messaging, sales enablement, competitive |
| `positioning` | Category, differentiation, market framing |
| `brand` | Brand building, creative, awareness, OOH |
| `content` | Editorial, SEO, AEO, thought leadership, community |
| `pricing` | Packaging, pricing strategy, monetisation |
| `revops` | Funnel definitions, attribution, tooling, sales–marketing alignment |
| `measurement` | Metrics, board reporting, benchmarks, CAC/payback |
| `leadership` | The marketing leader's job: first 90 days, managing up, the exec team |
| `team-building` | Hiring, org design, managing marketers |
| `ai` | AI in the marketing function |

Format tags (one per note, in `format:`, not `tags:`): `article` · `podcast` · `video` · `book` · `post` · `report` (PDFs: reports, ebooks, decks)

Freshness fields (`shelf_life`, `review_by`, `freshness`) are defined in [[freshness]].
