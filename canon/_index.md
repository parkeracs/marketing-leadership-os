# Canon

The trusted sources: the people and publications whose thinking you rely on. One note per creator: **why they matter, their lens, their blind spots.** An index of *why*, not an archive of *what* — specific pieces live in `library/` and link back here via `author`.

`/advise` searches these domains first when it goes to live sources.

## Note structure

Every canon note follows the same shape, so Obsidian views and `/advise` can rely on it:

```markdown
---
domain: <main domain>
description: "<one sentence: who they are>"
subscription: <paid or free, only if relevant>
tags: [<from taxonomy.md>]
links: { website, newsletter, podcast, youtube, linkedin, x }   # only verified links
---

# <Name>

<the description again, as the first line>

**Why I trust them:** …
**Lens:** …
**Use for:** … (link the relevant playbooks)
**Blind spots:** …
**Access:** … (only for paid or private sources)
```
